# Maverick Vault 🔐

A secure, locally-hosted password manager featuring AES-256 bit encryption and an intuitive graphical user interface. Built to keep credentials entirely offline and under user control.

## 🚀 Features
* **Zero-Knowledge Architecture:** Master password protection ensures only you can access your vault.
* **Military-Grade Encryption:** Utilizes Fernet (AES) to encrypt all stored credentials.
* **100% Offline:** No cloud syncing, zero third-party servers, and complete data sovereignty.
* **Clean UI:** Lightweight Tkinter graphical interface for seamless navigation.


## 🛠️ Tech Stack
* **Language:** Python 3
* **GUI:** Tkinter
* **Cryptography:** `cryptography.fernet`
